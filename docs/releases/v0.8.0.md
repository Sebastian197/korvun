# Korvun v0.8.0 — Beta

Every beta criterion is now met. The eighth release closes the last piece of the
beta — **minimal memory, governed** — on top of everything already shipped:
channels, multi-brain routing, the policy engine, resilience, the no-code builder,
the operator console, and governed tools & skills — each validated on real
hardware. Design: the
[minimal-memory spec](../superpowers/specs/2026-08-16-minimal-memory.md) and
[ADR-0043](../adr/0043-minimal-memory-notes-and-recall.md).

## Highlights

### Minimal memory, governed (ADR-0043)

Agent brains can now remember on purpose:

- **A governed `memory_note` tool.** The model writes bounded notes through the
  same tri-state gate as every tool (allow / rehearsal / deny per brain and
  channel, audited, capped): announce it in rehearsal first, watch what it
  *would* store, then promote it live.
- **Scoped by declaration.** Notes ride the system prompt only within their
  scope — per-conversation by default, brain-global as an explicit opt-in — as an
  inert, clearly-delimited data block, never instructions.
- **The operator stays in charge.** `/notes` lists the scope's notes; `/notes
  clear` removes them. Refuse-when-full, never silent eviction.
- **Privacy is structural.** Brain-global memory refuses to boot with a
  cloud-selected model, and a private brain's notes never leave the machine —
  proven by an end-to-end test against a local model.

### Deliberate recall

- `/new` still cuts hard — a session reset remains a hard context cut.
- `/recall` imports the previous session's tail as **ONE clearly-quoted block** —
  provenance visible in the block's own header, duplication impossible (only into
  an empty session), bounded, and only because you asked. Channel-agnostic: it
  works from Telegram, the console, or any routed channel.

### Redesigned website

The public site ships redesigned, with the full **EN/ES mirror** intact.

## Compatibility

Fully additive. The `brains[i].agent.memory` block, the `memory_note` tool, and
`session.recall_max` all default to absent — a v0.7.0 config parses and behaves
exactly as before. New fail-loud validations only fire when the new blocks are
present (memory requires storage and a governance grant; brain-global scope
requires a locally-selected model; `/recall` and `/notes` are reserved command
tokens in `session.triggers`). No new runtime dependency; `go.mod` is unchanged.

## Minor

- `/recall` and `/notes` are exact-first-token commands with fixed, bounded
  replies; on self-persisting channels their acknowledgements persist as system
  turns, skipped from model context.
- The conversation store grows a notes table and a bounded session-tail read —
  additive, no versioned migration; deleting a conversation deletes its notes.

## Artifacts

Two families in one release, exactly as v0.7.0. `<ver>` is the version without the
leading `v` (e.g. `0.8.0`).

| Family | Artifact | Target |
|--------|----------|--------|
| Headless | `korvun_<ver>_{linux,darwin}_{amd64,arm64}.tar.gz`, `korvun_<ver>_windows_{amd64,arm64}.zip` | server / CLI, six OS·arch |
| Headless | `checksums.txt` + `.sig` + `.pem`, per-archive `*.sbom.json` | signed manifest + SBOMs |
| Desktop | `korvun-desktop_<ver>_darwin_universal.dmg` | macOS universal app |
| Desktop | `korvun-desktop_<ver>_windows_amd64-installer.exe` | Windows NSIS installer |
| Desktop | `korvun-desktop_<ver>_linux_amd64.tar.gz` | Linux binary + `.desktop` |
| Desktop | `checksums-desktop.txt` + `.sig` + `.pem` | signed desktop manifest |

**Draft-until-complete:** the release is born a draft and is published only once
**both** families and their signatures are present, so a broken desktop build can never
expose a half-populated public release (ADR-0035 §8; SP7 §1e).

## Verifying this release

Both families are signed keyless with [cosign](https://github.com/sigstore/cosign)
(Sigstore), each with its own manifest. Verify the manifest signature you need, then
check your download against it.

Headless:

```sh
cosign verify-blob checksums.txt \
  --signature checksums.txt.sig \
  --certificate checksums.txt.pem \
  --certificate-identity-regexp 'https://github.com/Sebastian197/korvun/.*' \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com
```

Desktop:

```sh
cosign verify-blob checksums-desktop.txt \
  --signature checksums-desktop.txt.sig \
  --certificate checksums-desktop.txt.pem \
  --certificate-identity-regexp 'https://github.com/Sebastian197/korvun/.*' \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com
```
