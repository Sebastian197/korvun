# Korvun v0.10.0 — Beta: the honest desktop

The whole arc since v0.9.2, driven end to end by the house's Sixth Law:
every user-visible piece opened only after an experience design approved
over rendered mockups, and this release was gated by the director's manual
bug bash over the packaged build — zero use-breakers found. The theme is
honesty: the app never shows you protocol internals, never lies about who
is thinking, and never fails in silence.

## The chat never lies

- **Protocol JSON never reaches a channel (B13).** The 2026-08-23 incident
  — a small model hallucinated a tool call as plain text and the raw JSON
  landed in a real Telegram chat with zero log trace — is structurally
  closed. A registry-free shape detector guards the agent's single exit
  seam (text lane, native lane, and the degrade path): a reply whose whole
  body is a tool-call-shaped JSON object becomes a brief honest error, is
  logged with the phantom tool's name, audited with finite labels, and is
  never persisted into conversation memory.
- **The truthful wait (B11).** "The local model is thinking" was
  hardcoded — a double lie when a cloud brain answered. The wait now names
  the truth: *«openrouter está pensando — openrouter/auto · nube…»*, fed
  by the conversation's own brain and the live model health data; the
  long-wait line forks by locality, and with missing data the caption
  drops detail rather than inventing it.
- **The visible failure (B12).** When a request dies (provider error,
  policy 404, dead model), the wait CUTS and a band says so with a retry
  at hand — never an eternal "Thinking…". A repeated failure adds the two
  real fixes (the Builder for the model, Secrets for the key). After 60
  seconds without an answer the app warns and offers to keep waiting or
  retry — it never cuts on its own (a real local model on modest hardware
  legitimately takes over a minute). Error states are UI-only: the store
  keeps real turns, the permanent record is the Activity feed.

## The desktop grows its missing rooms

- **Pick the brain on New chat (B9).** A direct chat can be born addressed
  to any configured brain — the OpenRouter gymkhana (editing routes to try
  another brain) is dead. The choice travels inside the conversation's own
  id, survives restarts with zero schema change, and shows as a badge in
  the header and inbox. The router honors the contract on the console
  channel ONLY — a network-fabricated conversation id can never bypass its
  route (privacy invariant, test-pinned).
- **The Secrets panel (B10).** Ajustes gains a SECRETOS card: one row per
  secret NAME the config references, presence shown from booleans (env
  wins over keychain, and the row says so), write-only in-row editing over
  the OS keychain, confirmed deletion. It works with the core STOPPED —
  exactly when a boot broken by a missing secret needs it. The invariant
  is test-negative: no value ever appears in the DOM, transits an API, or
  is carried by any new surface.
- **The onboarding speaks gateway (N1).** The first-run Modelo step now
  offers the OpenAI-compatible branch (LM Studio, llama.cpp, OpenRouter…)
  with the four mold fields, and it validates that the CHOSEN model
  actually exists on the server before the step can close — failures speak
  on screen with the fix at hand. The first-run template is rewritten to
  the compat entry only after passing full config validation.
- **Delete a cable with the mouse (B8-bis).** The selected route cable
  grows a floating ✕ at its midpoint (the React Flow Button-Edge pattern);
  clicking it rides the exact same path as Backspace. The composition edge
  never offers the gesture. Driven end to end against the real binary.
- **Activity declares its volatility (N4).** The feed's window-scoped
  nature is now stated where it counts: a status chip next to the title
  (*«En vivo · desde que se abrió la ventana»*, with a soft pulse that
  respects reduced-motion) and an empty state that says the feed empties
  with the window — only metadata, never content.
- **The model panel validates before Apply (B14).** The Sunday corruption
  (a secret NAME glued into `base_url`, an emptied key, a flipped
  locality) applied cleanly because each field was individually plausible
  to the core. The panel is now the first line: absolute http(s) URLs
  only, the glued-secret-name shape rejected by name, cloud entries
  without a key blocked — with field-level messages, while the server
  remains the final judge.

## Under the hood

- **A real routing defect caught by the deflake work:** when a gateway
  peer closed with a FATAL code, a concurrent heartbeat write error could
  mask the close code and send a permanent failure down the transient
  retry path (the exact mechanism behind an August CI red, recovered from
  the original logs). The peer's close code now outranks local write
  errors. The other two chronic flakes fell with root causes too: the
  builder e2e suite now starts every spec from a pristine fixture, and a
  test-harness key collision was matching fresh chats against old
  histories. No timeout was inflated anywhere.
- **The engineering standard is legible:** CONTRIBUTING.md and SECURITY.md
  rewritten to describe the method as it operates (TDD with the approved
  RED as a contract, rehearsal-then-master, draft-until-complete releases,
  the Sixth Law), with the product's security invariants in three lines
  and the exact cosign verification commands.

## The new face

v0.10.0 ships Korvun's new identity end to end: the **A1 governed K** —
three model signals enter the K tile, the policy decision fires, one
controlled reply exits. It is the same story everywhere you meet the
product: the website masthead animates it and a routing circuit follows
your scroll from section to section (korvun.dev); the README opens with a
one-shot controlled sequence that settles on the static mark; the desktop
app icon on macOS, Windows and Linux is regenerated from the same source;
and the CLI's interactive banner tells it in characters. The identity
gradient stays the locked teal→violet diagonal (ADR-0030, amended
2026-08-29); the reduced-motion experience is a complete static circuit.

## Compatibility

Additive release: no config schema changes, no storage migrations,
`go.mod` untouched. Conversations created before v0.10.0 keep today's
behavior byte-for-byte; brain-addressed conversations are a new id shape
that old versions simply treat as ordinary ids.

## Verify your download

Both families ship a sha256 manifest signed with cosign (keyless,
Sigstore) and an SPDX SBOM per platform:

```sh
cosign verify-blob checksums.txt \
  --signature checksums.txt.sig \
  --certificate checksums.txt.pem \
  --certificate-identity-regexp 'https://github.com/Sebastian197/korvun/.*' \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com
```

(Desktop family: the same command over `checksums-desktop.txt`.) Full
walkthrough: [`docs/packaging/INSTALL.md`](../packaging/INSTALL.md).
User guides: [`docs/CHAT.md`](../CHAT.md), [`docs/BUILDER.md`](../BUILDER.md),
[`docs/CONFIGURATION.md`](../CONFIGURATION.md).
