## 1. What the train does

- **P1-1 — the claim owns the authorization.**
  `ClaimApprovalParamsUnderDigest` (`internal/action/sqlite/approvals_v15.go`)
  conditions its purge on `approvals.status = APPROVED` and on the parked
  action's `state = APPROVED`, and after the purge, before the commit,
  `claimAuthorityTx` re-reads both states inside the same transaction. A
  request whose authority moved is refused as `ErrApprovalNoLongerApproved`
  and the transaction rolls back whole. The re-read sits after the purge
  because Codex's trigger is `AFTER UPDATE OF canonical_params`: it fires
  inside the purge, once the WHERE has already been evaluated.
- **P1-2 — `escapeUntrusted` judges by Unicode class.** The first cure added
  the five code points the order named to the enumerated list. The diff's
  adversary then showed eight more members of the same class still passing
  (U+2063, U+2061, U+00AD, U+180E, U+034F, U+FE0F, U+3164, U+E0041), so the
  list became a class: Cc, Cf, Cs, Zs except U+0020, Zl, Zp and
  Default_Ignorable_Code_Point render as visible `<U+XXXX>` escapes
  (`cmd/korvun-desktop/frontend/src/views/Approvals.tsx`). Its godoc says what
  it does NOT cover: characters with a glyph, even a blank one (U+2800), and
  look-alike characters.
- **P1-3 — a context that ends after the effect closes `OUTCOME_UNKNOWN` on the
  brain path.** `internal/brain/agent.go` closes `context.DeadlineExceeded` the
  way the approved path already did, and — the sister the diff's adversary
  found — `context.Canceled` too. On the approved path a cancellation after the
  claim closes nothing at all: captured on 2026-09-15 with a tool that cancels
  its own context, `FinishWithResult` failed with `begin finish: context
  canceled` and the action stayed `APPROVED`, so no FAILED claim is written and
  no cure is made there. The cage arm's `delivered` log field now reads
  `tool.ErrEffectDelivered` itself; deriving it from the close state would have
  logged a deadline as delivered.
- **The date bomb.** `TestOperatorAct_endToEnd` carried fixed calendar windows;
  on 2026-09-15 its parent grant expired and the test went red on every tree,
  `1817dd4` included (captured on a clean `git archive 1817dd4`). By the
  director's option (a) its windows are relative to the wall clock, and the
  «expired authority failing closed» its header promised — exercised by no
  step — is now its own named attack.
- **Public sentences that were false.** «Three defects» over a list of four in
  `docs/releases/v0.15.0.md`; «loopback» said of the admin server without «by
  default» in `README.md` and the website (en/es `what-is-korvun`,
  `operator-cli`). The approvals API rides the admin server
  (`RegisterApprovals(adminServer, …)` in `internal/app/app.go`), which binds
  `observability.addr` and accepts `0.0.0.0`. The same false sentence lived in
  the CLI: `korvun approvals show` printed `raw parameters (loopback only):`;
  scoped down to `raw parameters:`, with its comment, by the director's ruling
  that a false sentence is not published whether it is on the list or not.
