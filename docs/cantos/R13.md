### A13 — sqlite3's dot-command tokenizer and a quoted id (3.39.5)

```
$ sqlite3 :memory: ".param set @apr 'it''s'" "SELECT quote(@apr);"
.parameter CMD ...       Manage SQL parameter bindings
   ... (the usage block) ...
NULL
exit=0
$ sqlite3 :memory: ".param set @apr \"it's\"" "SELECT quote(@apr);"
'it''s'
exit=0
$ sqlite3 :memory: ".param set @apr \"a\\\"b\"" "SELECT quote(@apr);"
'a"b'
exit=0
```
The single-quoted spelling with a doubled quote prints the usage, exits
0 and leaves the parameter UNBOUND — a silent miss; the double-quoted
form binds the exact bytes. The document shows the double-quoted form
and names the miss.
