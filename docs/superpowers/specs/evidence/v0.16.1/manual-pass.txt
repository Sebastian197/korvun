# v0.16.1 — manual pass over the CLI delegation door

Date: 2026-09-23. Binary built from this tree with `go build ./cmd/korvun`, run
against a profile created from scratch under `/tmp`. Nothing here touches an
existing store.

**WHAT THIS IS, AND WHAT IT IS NOT.** It drives the door a real operator uses —
a real signed intent, a real signed grant issued through `authority admin-issue`,
and `intent bind --grant` — against a real SQLite file, and reads the result back
through a SEPARATE read-only connection. It is **not** the pass over the PACKAGED
build: that one runs the `.app` and lives in `packaged-pass.txt` beside this file.
And **no model runs here**, because the piece under test is an operator door, not
a model-dependent surface; the law that demands a real model covers what a model
emits, and nothing in this sequence does.

**The grant file is generated by the repository's OWN canonical encoder**, from
the store's own signed intent, rather than typed by hand — a hand-typed grant
would be testing my typing, not the door.
